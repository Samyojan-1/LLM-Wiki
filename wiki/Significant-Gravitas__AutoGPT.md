# AutoGPT: Build, Deploy, and Run AI Agents

> A platform for building, deploying, and running continuous AI agents that automate complex workflows.

- **Repository:** https://github.com/Significant-Gravitas/AutoGPT
- **Stars:** 185373

## What it is

AutoGPT is a platform for creating, deploying, and managing AI agents that run continuously and automate multi-step tasks. It provides a low-code Agent Builder where agents are assembled by connecting blocks, each performing a single action, plus a server component that runs and triggers deployed agents. The repository also contains "AutoGPT Classic," the original standalone agent along with a toolkit (Forge), a benchmark (agbenchmark), and a CLI for building and testing agents that speak the agent protocol standard.

## What it's good for

- Building automation workflows visually by connecting pre-built blocks rather than writing code
- Deploying agents that run continuously and can be triggered by external sources
- Selecting from a marketplace of ready-to-use, pre-configured agents instead of building from scratch
- Monitoring agent performance and behavior after deployment
- Building and benchmarking custom agents from scratch using the Forge toolkit and agbenchmark (Classic)

## Key features

- Agent Builder: a low-code, block-based interface for designing agent workflows
- AutoGPT Server: the runtime that executes deployed agents and can trigger them from external events
- Marketplace of pre-built, ready-to-run agents
- Forge: a boilerplate toolkit for building custom standalone agents (Classic)
- agbenchmark: a testing framework for objectively evaluating agent performance against the agent protocol
- CLI for creating, running, and benchmarking agents locally
