# LLM Wiki Index

## framework

- [[FoundationAgents__MetaGPT]] — A multi-agent framework that assigns GPT-based agents distinct software-company roles to collaboratively turn a one-line requirement into a working software project.
- [[infiniflow__ragflow]] — An open-source Retrieval-Augmented Generation engine that combines document understanding with agent capabilities.
- [[langchain-ai__langchain]] — A Python framework for building agents and LLM-powered applications from interoperable components.
- [[microsoft__ai-agents-for-beginners]] — A free Microsoft course of lessons that teaches the fundamentals of building AI agents.
- [[Significant-Gravitas__AutoGPT]] — A platform for building, deploying, and running continuous AI agents that automate complex workflows.

## memory

- [[letta-ai__letta]] — A platform for building stateful AI agents with advanced memory that persists and improves over time.
- [[thedotmack__claude-mem]] — A plugin that gives Claude Code (and similar agents) persistent memory across sessions by compressing and re-injecting past context.

## skills/plugins

- [[ComposioHQ__awesome-claude-skills]] — A curated, community-maintained list of over 1000 Claude Skills and plugins for extending Claude across Claude.ai, Claude Code, and the Claude API.
- [[DietrichGebert__ponytail]] — A Claude Code / multi-agent-host plugin that pushes coding agents to write the minimal amount of code needed, rather than over-engineering solutions.
- [[affaan-m__ECC]] — A large collection of agents, skills, hooks, and rules that installs into Claude Code (and other AI coding harnesses) to make coding agents more effective and consistent.
- [[code-yeongyu__oh-my-openagent]] — A plugin for the OpenCode (and Codex CLI) agent harness that adds a set of specialized subagents, orchestration modes, and developer tooling on top of the base coding agent.
- [[thedaviddias__Front-End-Checklist]] — An open-source, structured checklist of front-end quality rules, usable via a website, an MCP server, or this README.

## orchestration

- [[NousResearch__hermes-agent]] — A self-improving AI agent, built by Nous Research, that can be run from a terminal or messaging platforms and learns from experience over time.
- [[bytedance__deer-flow]] — An open-source "super agent harness" that runs long, multi-step agent tasks — research, coding, content creation — using sandboxes, memory, skills, and coordinated sub-agents.
- [[ruvnet__ruflo]] — An agent meta-harness that wraps Claude Code and Codex with multi-agent coordination, persistent memory, and self-learning.

## tooling

- [[Mintplex-Labs__anything-llm]] — An all-in-one, self-hostable application for chatting with your documents and running AI agents, configurable with a wide range of LLM, embedding, and vector-database providers.
- [[browser-use__browser-use]] — A Python library that lets an LLM-driven agent control a real web browser to complete tasks online.
- [[daytonaio__daytona]] — Secure, elastic cloud infrastructure for spinning up isolated sandboxes to run AI-generated code.
- [[firecrawl__firecrawl]] — An API that searches, scrapes, and interacts with the web at scale, turning pages into clean data for AI agents.
- [[google-gemini__gemini-cli]] — An open-source terminal agent that gives direct command-line access to Google's Gemini models.
- [[nexu-io__open-design]] — A local-first, open-source desktop app that turns coding-agent CLIs into a design engine for prototypes, decks, images, and video.

## other

- [[dair-ai__Prompt-Engineering-Guide]] — A curated, continuously updated guide of papers, techniques, tools, and courses on prompt engineering for large language models.
