# AI Agents for Beginners

> A free Microsoft course of lessons that teaches the fundamentals of building AI agents.

- **Repository:** https://github.com/microsoft/ai-agents-for-beginners
- **Stars:** 68534

## What it is

This is a structured course, not a library or framework. It consists of a series of lessons — each with a written README, code samples, and an accompanying video — that walk a learner through the concepts needed to build AI agents from scratch. The code samples use the Microsoft Agent Framework (MAF) together with Azure AI Foundry Agent Service V2, and some samples also support OpenAI-compatible providers. The course is translated into 50+ languages via an automated GitHub Action.

## What it's good for

- Learning what AI agents are and common use cases, from a beginner starting point
- Following along with runnable Python code samples per lesson rather than just theory
- Understanding specific agentic design patterns (tool use, planning, multi-agent, metacognition) one at a time
- Learning agentic protocols like MCP and A2A in a dedicated lesson
- Studying agent memory, context engineering, and production/security concerns for agents

## Key features

- 12+ lessons covering topics from "Intro to AI Agents" through multi-agent design, production deployment, and securing agents
- Each lesson pairs a written README with Python code samples and a short video
- Built around Microsoft Agent Framework and Azure AI Foundry Agent Service V2
- Multi-language support (50+ translations) automatically kept up to date
- Links out to related Microsoft "for Beginners" courses (Generative AI, LangChain, MCP, etc.)
- Sparse-checkout instructions provided for cloning without the large translations folder
