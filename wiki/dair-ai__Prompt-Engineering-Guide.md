# Prompt Engineering Guide

> A curated, continuously updated guide of papers, techniques, tools, and courses on prompt engineering for large language models.

- **Repository:** https://github.com/dair-ai/Prompt-Engineering-Guide
- **Stars:** 76208

## What it is

This repository is the source for DAIR.AI's Prompt Engineering Guide, a reference resource for developing and optimizing prompts to use LLMs effectively. It collects introductory material, prompting techniques, applications, model-specific notes, risk/misuse discussions, and links to papers, all also published as a web version at promptingguide.ai. It is a documentation/content project (built with Next.js/Nextra) rather than a code library — the README itself is largely a table of contents pointing to guide pages.

## What it's good for

- Learning the basics of prompting: LLM settings, prompt elements, and general tips for writing effective prompts.
- Looking up specific prompting techniques such as zero-shot, few-shot, chain-of-thought, self-consistency, tree of thoughts, ReAct, RAG, and program-aided language models.
- Finding worked examples/prompts for tasks like classification, coding, summarization, question answering, and information extraction.
- Researching model-specific prompting notes (e.g., ChatGPT, GPT-4, LLaMA, Gemini, Mistral/Mixtral).
- Reviewing risks and misuses of prompting, such as adversarial prompting, factuality, and bias.

## Key features

- Structured guide sections: Introduction, Techniques, Applications, Prompt Hub, Models, Risks and Misuses, Papers, Tools, Notebooks, and Datasets.
- A published 1-hour video lecture with an accompanying Jupyter notebook and slide deck.
- Guide available in 13 languages via community translations.
- Companion paid courses ("DAIR.AI Academy") on prompt engineering, RAG, and AI agents.
- Can be run locally as a Next.js site (`pnpm i` + `pnpm dev`) to preview edits, e.g. new translations.
