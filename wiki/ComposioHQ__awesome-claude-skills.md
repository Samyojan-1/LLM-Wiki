# Awesome Claude Skills

> A curated, community-maintained list of over 1000 Claude Skills and plugins for extending Claude across Claude.ai, Claude Code, and the Claude API.

- **Repository:** https://github.com/ComposioHQ/awesome-claude-skills
- **Stars:** 66789

## What it is

This repository is a link directory, not a piece of software: it collects and organizes third-party and official Claude Skills — reusable instruction packages that teach Claude how to perform specific tasks. Skills are described as folders containing a SKILL.md file with YAML frontmatter plus optional scripts, templates, and reference files, loaded progressively so an agent can host hundreds of them without bloating its context window. The README also promotes a "connect-apps" plugin (built on Composio) that lets Claude take real actions across 500+ apps.

## What it's good for

- Finding an existing skill for a task (document processing, dev tooling, data analysis, marketing, etc.) instead of writing one from scratch.
- Learning the skill folder/SKILL.md structure and best practices before authoring a new skill.
- Discovering app-automation skills (CRM, email, project management, and more) that use Composio's Rube MCP to connect Claude to external services.
- Browsing categorized examples to understand what kinds of tasks the Claude Skills format is used for.

## Key features

- Skills organized into categories: document processing, dev tools, data & analysis, business/marketing, communication, creative/media, productivity, collaboration, security, and app automation.
- A large "App Automation via Composio" section listing pre-built workflow skills for dozens of SaaS apps (CRM, project management, email, storage, analytics, etc.).
- Explains the Skills format itself (SKILL.md, progressive loading, relationship to MCP and tools).
- Includes a basic skill template and guidance for creating and contributing new skills.
- Links to official Anthropic documentation and community resources on Skills.

## Category

skills/plugins — the repository is entirely a curated catalog of Claude Skills and plugins, plus documentation on how to build and use them.
